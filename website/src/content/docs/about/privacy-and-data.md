---
title: 账号安全与数据归属
description: Campanula 的网易云凭据加密方式、网络流量分流机制与本机数据存储边界。
---

Campanula 采用无数据库架构，站长部署的服务器实例不保存任何听众的网易云凭据或个人曲库记录。

## 网易云凭据保护

- **加密保存在听众浏览器**：登录成功后，服务端使用站长配置的 `COOKIE_SECRET` 对网易云会话凭据（包含 `MUSIC_U`）进行加密与签名，再写入 `httpOnly`、`Secure` Cookie。页面脚本无法读取 Cookie 明文，凭据也不会出现在请求 URL 中。
- **服务端无状态处理**：每次经过实例接口的请求会携带加密 Cookie，服务端解密并请求网易云接口后即释放内存，不写入磁盘或数据库。
- **更换密钥的影响**：站长修改 `COOKIE_SECRET` 后，所有听众的旧 Cookie 均无法解密，需要重新登录。
- **退出登录边界**：联网退出会清除当前浏览器 Cookie，但由于服务端不集中存储会话列表，无法使此前已泄露的凭据在网易云侧即时失效；断网状态下退出会立即把本地界面切回未登录态，待重新联网后由服务端清除 Cookie。

## 网络流量分流

| 流量类型 | 经过路径                       | 包含请求                                               |
| -------- | ------------------------------ | ------------------------------------------------------ |
| 业务接口 | 听众浏览器 → 自建实例 → 网易云 | 登录、同步曲库、搜索、获取播放地址、编辑歌单与听歌打卡 |
| 媒体直连 | 听众浏览器 → 网易云存储节点    | 音频在线播放、离线下载音频流、自建歌单封面上传         |

音视频流与歌单封面上传由浏览器直连网易云，不消耗站长服务器带宽与函数流量配额。

## 本地数据存储与归属

| 数据类型           | 存储位置             | 退出或换账号后 | 生命周期说明                                                                     |
| ------------------ | -------------------- | -------------- | -------------------------------------------------------------------------------- |
| 曲库副本与播放队列 | 当前浏览器 IndexedDB | 清除           | 打开应用时优先从本地渲染，后台再与网易云增量同步                                 |
| 已下载歌曲与断点   | 当前浏览器本机存储   | 保留           | 归属当前设备、浏览器与域名，与登录及会员状态无关，仅手动清除或清理站点数据后消失 |
| 导出的音频文件     | 听众选定的本地文件夹 | 独立留存       | 含完整标签、封面图与歌词的普通音频副本，导出后不再由 Campanula 管理              |

更换部署域名或切换浏览器时，原有已下载歌曲不会自动迁移；切换地址前可按[下载管理与导出](../guide/listen.md#下载管理与导出)将歌曲导出至本地文件夹。
