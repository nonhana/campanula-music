title: 账号安全与数据归属
description: 网易云凭据如何保管、流量怎么走，以及曲库与下载各自存放在哪。
---

Campanula 以站长自部署为主，服务器无数据库、不保存任何听众的网易云凭据。

## 网易云凭据如何保管

- **加密存于听众浏览器**：登录后，服务器使用站长配置的 `COOKIE_SECRET` 对网易云凭据（以 `MUSIC_U` 为核心）加密签名，写入 `httpOnly`、`Secure` Cookie 交由听众浏览器保管。页面脚本无法读取，凭据也不会出现在 URL 中。
- **服务器即用即弃**：每次接口请求带上加密 Cookie，服务器解密调用网易云后即丢弃，不写磁盘、不落库。
- **更换密钥的影响**：站长更换 `COOKIE_SECRET` 后，所有听众都需要重新登录。
- **退出登录的边界**：联网退出会清除当前浏览器的 Cookie，但服务端不集中保存会话，无法保证此前已泄露的凭据在网易云侧立即失效；断网退出时 App 立即按未登录处理，待重新联网后由服务端清除 Cookie。

## 网络流量如何传输

- **轻量接口走实例**：登录、同步曲库、搜索、获取播放地址、歌单编辑等需要携带凭据的轻量请求经过站长部署的 Campanula 实例。
- **大流量浏览器直连**：在线播放音频、离线下载音频以及歌单封面上传，均由听众浏览器直接与网易云存储服务器通信，不中转站长服务器带宽。

## 本机数据分别归谁

| 数据               | 存放位置             | 退出或换账号时 | 说明                                                                        |
| ------------------ | -------------------- | -------------- | --------------------------------------------------------------------------- |
| 曲库副本与播放队列 | 当前浏览器 IndexedDB | 清除           | 本地优先加载，断网可浏览曲库，后台与网易云增量同步                          |
| 已下载歌曲与断点   | 当前浏览器本机存储   | **保留**       | 归属设备与当前域名/浏览器，与登录和会员状态无关，仅手动删除或清站点数据消失 |
| 导出的音频文件     | 听众选定的本地文件夹 | 独立留存       | 含完整标签、封面与歌词的普通音频副本，导出后不再归 Campanula 管理           |

更换部署域名或更换浏览器时，原地址下的已下载歌曲不会自动迁移；换地址前可先按[安装与离线播放](../guide/listen.md#保存与导出下载)导出。
