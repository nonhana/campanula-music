Campanula 以「清晨的风铃草」为视觉基调，通过克制的浅色界面与低干扰排版，将视觉焦点让渡给音乐与封面图。

## 浅色视觉体系

全站采用薄荷晨光底色配纸白卡片面板以建立清晰层级；进入播放页时，系统以当前歌曲封面图的高斯模糊与浅雾蒙层生成背景，使每首曲目具备独立氛围的同时保持文本对比度。

为保障桌面端与手机端在不同封面亮度下的对比度稳定性，Campanula 专注打磨浅色主题，不随系统反色切换，亦不提供深色模式。

## 色彩分工与多语种字体

| 语义色系  | 界面唯一职责                                     |
| --------- | ------------------------------------------------ |
| 薄荷      | 正在播放状态、列表选中项、播放进度条与键盘焦点环 |
| 珊瑚      | 红心动作与「我喜欢的音乐」标识                   |
| 蜜桃      | 当前设备专属状态：下载入口、已下载标记与离线提示 |
| 琥珀 / 红 | 试听片段徽标、下载失败与删除确认等警示           |

曲库内容常同时包含简体中文、繁体中文、日文假名与拉丁字符。应用内置自托管 Noto Sans 可变字体族（拉丁、简体、日文、繁体），按语种自动匹配字形并统一约束为 `400`、`500`、`600` 三个真实字重，避免系统字体回退导致的排版高度跳动与间距失衡。

动效只承担三项信息职责——确认操作响应、交代元素空间流向与标示当前状态，不回弹、不阻塞操作：

- **封面引导转场**：从曲库网格进入歌单、专辑或歌手页时，基于浏览器原生 View Transitions 使封面图飞入页头；点歌起播时封面图落入底部播放条，切歌时完成流畅的「换碟」过渡。
- **晨光行与波浪进度**：正在播放歌曲在列表行内铺开浅薄荷光晕；播放页已播进度以正弦波纹呈现，暂停或拖动进度条时随即拉平。
- **歌词选字与时间定位**：桌面端歌词支持直接拖选复制原文；手动滚动歌词时在视线基准线显示时间胶囊以点击跳转，当前高亮行放大时不破坏原有换行。
- **支持减少动态效果**：检测到系统开启「减少动态效果」时，自动收起所有位移、飞入与循环动画，仅保留短时淡入淡出。
