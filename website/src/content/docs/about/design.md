Campanula 的界面以「清晨的风铃草」为灵感：整体克制安静，把视觉重心留给色彩浓烈的歌曲封面。

## 为什么只有浅色主题

整页铺一层极淡的薄荷晨光底，面板像轻轻浮在上面的纸白卡片；播放器页面以当前封面重度模糊并叠加白纱染出浅雾底色，让每首歌拥有自己的氛围同时保持文字清晰可读。

为保证手机与桌面每一处界面和对比度都维持一致完成度，Campanula 专注打磨浅色主题，不跟随系统反色，也不提供深色模式。

## 色彩分工与混排字体

| 颜色系    | 唯一分工                                           |
| --------- | -------------------------------------------------- |
| 薄荷      | 正在播放、选中态、播放进度、键盘焦点               |
| 珊瑚      | 红心与「我喜欢的音乐」标记                         |
| 蜜桃      | 属于当前设备的内容：下载按钮、已下载状态与断网提示 |
| 琥珀 / 红 | 试听徽标与下载失败、删除确认等警示                 |

听众曲库常包含大量日文假名、英文、繁体与简体中文混排标题。界面自托管 Noto Sans 可变字体族（拉丁、简体、日文、繁体），按文本语种自动切换字形并只使用 400 / 500 / 600 三个真实字重，消除字体回退造成的不均匀间距。

## 克制的动效与交互

动效只解释三件事：操作是否生效、元素从哪来到哪去、现在处于什么状态，不回弹、不拖慢操作。

- **封面引导转场**：列表进入歌单、专辑、歌手页时使用浏览器原生 View Transitions，封面从网格飞到页头；点歌时封面沿浅弧落入播放条；切歌时封面像挂在转盘边缘顺势「换碟」。
- **晨光行与波浪进度**：正在播放行随进度铺开一层浅薄荷光；播放页已播进度以轻缓正弦波流动，暂停或拖动时立刻抹平。
- **歌词选字与跳转**：桌面歌词可直接拖选复制原文，手动滚动时在视线基准线浮出固定时间胶囊点击跳转，当前行放大不破坏原有换行。
- **尊重减少动态效果**：开启系统「减少动态效果」后，所有位移、飞行与循环动画自动收起，仅保留短时淡入淡出。
