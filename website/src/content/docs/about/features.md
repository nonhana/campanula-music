---
title: 功能与边界
description: Campanula 提供什么、刻意不做什么，以及支持的浏览器与交互方式。
---

Campanula 只保留网易云音乐里**听歌、搜歌、整理曲库**这一条主线：登录自己的网易云账号后直接进入曲库，没有推荐信息流与商业模块。

## 能做什么

| 板块       | 核心能力                                                                                                |
| ---------- | ------------------------------------------------------------------------------------------------------- |
| 曲库       | 我喜欢的音乐、自建歌单、收藏的歌单/专辑/歌手；本地优先加载与大歌单瞬时筛选                              |
| 搜索与发现 | 单曲、歌单、歌手、专辑搜索与输入建议、本机搜索历史、每日推荐                                            |
| 播放与歌词 | 播放队列、音质与播放模式切换、逐字/逐行歌词（含翻译、音译、选字复制与跳转）、锁屏与通知栏控制、听歌打卡 |
| 歌单整理   | 红心、加入歌单、收藏、新建/编辑/删除自建歌单、更换正方形封面、多选批量操作与拖动排序                    |
| 离线下载   | 单曲/整张歌单/整张专辑下载、断点续传、独立下载音质、按歌单清理及带元数据导出到文件夹                    |

受版权与会员规则限制，无版权歌曲置灰不可播放；非会员播放会员歌曲时仅播试听片段，且试听片段不可下载。

## 刻意不做

为了保持轻量与专注，以下功能不在计划内：

- **信息流与社交**：推荐广场、排行榜、私人 FM、最近播放、热搜榜、评论、动态/私信、MV、播客、云盘、商城、推送通知。
- **重型播放插件**：均衡器与音效、淡入淡出、定时关闭、桌面歌词。
- **多主题与多语言**：仅提供浅色主题与简体中文界面。

## 支持的浏览器与屏幕

- **推荐环境**：Android Chrome（可安装为独立应用）、桌面 Chrome 与 Edge（可安装为独立窗口）。不保证其他浏览器的安装与文件夹导出等增强能力；暂不考虑 iOS。
- **布局与交互**：视口窄于 `768px` 采用手机布局，`768px` 及以上采用桌面布局；操作细节随输入方式切换，例如窄桌面窗口使用鼠标时仍保留右键菜单，无需长按。

想了解凭据保管与离线数据归属，见[账号安全与数据归属](./privacy-and-data.md)；准备自己搭一个实例，见[部署指南](../guide/index.md)。
