先把播放器放到自己的网址，再用自己的网易云账号登录。

- [部署到 Vercel](./vercel.mdx)：不用准备服务器，配置密钥和自己的域名。
- [部署到自己的服务器](./server.md)：选择 Docker 或 Node，再配 HTTPS。

已经部署好，可以看[安装与离线播放](./listen.md)或[升级与回退](./upgrade.md)。想修改源码，请看[本地开发](../development/index.md)。
