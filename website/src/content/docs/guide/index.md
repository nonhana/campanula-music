---
title: 部署 Campanula
description: 选择部署方式，用自己的网易云账号开始听歌。
---

想用自己的网易云账号听歌，先部署一个自己的 Campanula 实例。这里收集现有的部署入口，按你的服务器条件选择一种方式。

现有的 [Node 和 Docker 部署说明](https://github.com/nonhana/campanula-music/blob/rewrite/v1/docs/self-hosting.md)适合有自己服务器的读者，里面说明了怎样启动实例、配置密钥与 HTTPS。部署前也可以先看 [README 的部署入口](https://github.com/nonhana/campanula-music/blob/rewrite/v1/README.md#部署)，确认需要准备的环境变量。

没有服务器、想用 Vercel 的读者，后续会有单独的部署教程；本页目前只链接已经写好的说明。

部署完成后，打开自己的 HTTPS 地址，看到登录页就可以用自己的网易云账号登录。升级时保留原来的加密密钥，具体步骤见上面的部署说明。
