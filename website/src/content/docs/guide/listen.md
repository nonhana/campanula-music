打开播放器的 HTTPS 地址，用自己的网易云账号扫码或短信登录。还没有实例时先[部署播放器](./index.md)。

## 安装到手机或电脑

| 浏览器         | 安装入口                                                               |
| -------------- | ---------------------------------------------------------------------- |
| Android Chrome | 菜单 →「安装并创建快捷方式」→「安装」。                                |
| 电脑 Chrome    | 地址栏安装图标，或菜单 →「投放、保存和分享」→「将网页安装为应用」。    |
| 电脑 Edge      | 地址栏安装图标，或菜单 →「更多工具」→「应用」→「将此站点安装为应用」。 |

从系统图标打开 Campanula。找不到安装入口时，先检查 HTTPS 和应用是否已安装，也可以继续用浏览器标签页访问。

## 下载并验证离线播放

1. 联网打开一次播放器。选一首能完整播放的歌，在歌曲更多菜单中点「下载」。
2. 在「设置 → 已下载」确认歌曲已出现在列表里。等下载完成再关闭页面。
3. 关闭所有 Campanula 标签页和窗口，断开 Wi-Fi 和移动数据。
4. 重开应用或原地址，确认出现离线提示，并在「已下载」播放刚才那首歌。

下载只在应用页面打开期间进行；中途关闭或刷新后，排队和断点会自动保留，下次打开接着下。

| 现象                         | 处理                                                             |
| ---------------------------- | ---------------------------------------------------------------- |
| 短信报 10004                 | 改用扫码，或请站长检查[登录配置](./server.md#打开自己的登录页)。 |
| 断网打不开                   | 恢复网络，用原浏览器打开原地址，再试一次。                       |
| 看得到歌单，歌曲无法离线播放 | 到「已下载」确认该歌曲已下载完成。                               |
| 换设备后找不到下载           | 回到原设备、原浏览器和原地址。                                   |

## 保存与导出下载

- 退出或切换账号后，同一浏览器仍可播放、删除这份下载；清理站点数据会清除下载（详见[账号安全与数据归属](../about/privacy-and-data.md)）。
- 存储空间不足时会暂停整个下载队列，腾出空间后点「继续下载」从断点恢复。
- 要另存为音频文件，在「已下载」打开歌曲菜单，选「导出」并选择文件夹。支持选文件夹的 Android Chrome、桌面 Chrome 和 Edge 会显示此入口。
- 导出成功后可删除 App 内的下载，导出的文件仍在所选文件夹里。

## 日常使用提示

- **单点即播**：曲库与搜索列表单击整行即可播放；桌面端右键歌曲行打开更多菜单，歌手与专辑名可直接点击跳转。
- **歌词选字与跳转**：桌面播放页可直接拖选复制歌词原文；滚动歌词时右侧出现时间胶囊，点击跳至该句播放。手机端轻点歌词行即可跳转。
- **桌面返回与多选**：安装为独立窗口后可用顶栏左上角的返回/前进键跨页；列表表头右侧进入多选，支持 ⌘ / Ctrl 点选与 Shift 连选。
