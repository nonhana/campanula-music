通过站长提供的 HTTPS 地址打开 Campanula 后，使用自己的网易云账号扫码或短信登录。若尚未搭建站点，可先查阅[部署指南](./index.md)。

## 安装为独立应用

| 浏览器         | 安装入口                                                                 |
| -------------- | ------------------------------------------------------------------------ |
| Android Chrome | 菜单 →「安装并创建快捷方式」→「安装」                                    |
| 桌面 Chrome    | 地址栏右侧安装图标，或菜单 →「投放、保存和分享」→「将网页安装为应用」    |
| 桌面 Edge      | 地址栏右侧安装图标，或菜单 →「更多工具」→「应用」→「将此站点安装为应用」 |

安装完成后可从桌面或主屏幕图标独立启动。若浏览器未显示安装入口，检查当前页面是否已通过 HTTPS 访问、应用是否已存在，或继续通过普通标签页使用。

## 离线下载与验证

1. 联网打开一次应用，选取一首可完整播放的曲目，在歌曲更多菜单中点击「下载」。
2. 在「设置 → 已下载」确认该曲目已完成下载，完成后再关闭页面。
3. 关闭全部 Campanula 标签页与独立窗口，断开网络（Wi-Fi 与移动数据）。
4. 重新打开应用或原域名地址，确认页面进入离线状态并可在「已下载」列表正常播放已下载曲目。

下载仅在应用页面处于打开状态时执行；若中途关闭窗口或刷新页面，当前队列与断点会持久化保存，待下次打开应用时自动恢复。

| 异常现象             | 处理方式                                                           |
| -------------------- | ------------------------------------------------------------------ |
| 短信登录返回 10004   | 改用扫码登录，或联系站长核对[验证部署](./server.md#验证部署)配置   |
| 离线状态无法打开应用 | 恢复网络后使用同一浏览器再次访问原域名以完整加载页面外壳，随后重试 |
| 歌单可浏览但无法播放 | 前往「已下载」列表确认目标曲目已全部下载完成                       |
| 更换设备后无下载记录 | 离线歌曲保存在本机浏览器存储中，需回到原设备、原浏览器及原域名查看 |

## 下载管理与导出

- 退出登录或切换网易云账号后，同一浏览器仍可播放或删除已下载歌曲；清理浏览器站点数据会一并移除下载内容（详见[账号安全与数据归属](../about/privacy-and-data.md)）。
- 设备存储空间不足时，系统会自动暂停整个下载队列；清理磁盘空间后在下载管理页点击「继续下载」即可从断点继续。
- 支持文件夹访问接口的浏览器（Android Chrome、桌面 Chrome 与桌面 Edge）可在「已下载」歌曲菜单中执行「导出」，将包含完整标签、封面图与歌词的音频副本写入选定文件夹。
- 导出完成后即使在应用内删除该歌曲的下载副本，已写入本地文件夹的音频文件仍独立保留。

## 常用交互提示

- **列表播放与跳转**：在曲库或搜索结果列表中单击歌曲行即可播放；桌面端支持在歌曲行右键呼出操作菜单，点击歌手或专辑名称可直接跳转对应详情页。
- **歌词选字与定位**：桌面端播放页支持直接拖选并复制歌词文本；手动滚动歌词时右侧出现固定时间胶囊，点击可跳转至对应句；手机端轻点歌词行即可跳转。
- **独立窗口导航与多选**：以独立应用窗口打开时可使用顶栏左上角返回/前进按钮跨页；通过列表表头右侧开关进入多选状态，桌面端支持 ⌘ / Ctrl 点选与 Shift 连选。
