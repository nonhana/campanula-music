准备 GitHub 账号、已连接 GitHub 的 Vercel 账号和一个自己的域名。

## 生成并保存密钥

```bash
openssl rand -base64 32
```

在本机运行命令，把**输出**存进密码管理器，部署时填入 `COOKIE_SECRET`。也可以用密码管理器生成至少 32 个字符的随机密码。升级沿用原值。

## 创建播放器项目

<DeployAction />

1. 选择 GitHub 账号，填写新仓库名。按钮会复制 [Campanula 主分支 `master`](https://github.com/nonhana/campanula-music/tree/master)。
2. 在 **Environment Variables** 填入 `COOKIE_SECRET`，应用到 **Production**。
3. 核对构建设置，点击 **Deploy**。若出现 **Verify Your Identity**，按 Vercel 提示验证后继续。
4. 到 **Deployments** 找到 **Ready** 的记录，检查 **Source** 是刚复制的 v1 代码，函数地区为 **Hong Kong (`hkg1`)**。修正设置后重新部署。

| 构建设置         | 值                               |
| ---------------- | -------------------------------- |
| Root Directory   | 留空（仓库根目录）               |
| Framework Preset | SvelteKit                        |
| Install Command  | `pnpm install --frozen-lockfile` |
| Build Command    | `pnpm build`                     |

创建页未显示构建设置时，到项目的 **Settings → Build and Deployment** 核对。修改命令时打开对应的 **Override**，保存后重新部署。 [Vercel 构建设置](https://vercel.com/docs/builds/configure-a-build)

### 手动导入

1. Fork [Campanula 仓库](https://github.com/nonhana/campanula-music)。
2. 在 Vercel 通过 **Add New → Project** 导入 Fork，使用默认分支 `master`。
3. 按上表设置构建并填写 `COOKIE_SECRET`，点击 **Deploy**。

## 绑定自己的域名

1. 在项目的 **Settings → Domains** 添加播放器域名，例如 `music.example.com`。
2. 在 DNS 服务商处按 Vercel 显示的类型、名称和目标添加记录。CNAME 使用项目提供的目标，避开 `*.vercel.app`。使用 Cloudflare DNS 时选 **仅 DNS**。
3. 回到 **Domains**，等配置验证通过和 HTTPS 证书就绪。 [Vercel 域名配置](https://vercel.com/docs/domains/working-with-domains/add-a-domain)

## 打开自己的登录页

打开自己的 HTTPS 地址，确认能看到网易云登录入口。

| 现象              | 检查                                                                |
| ----------------- | ------------------------------------------------------------------- |
| 需要配置加密密钥  | 检查 Production 的 `COOKIE_SECRET` 至少 32 个字符，保存后重新部署。 |
| 需要用 HTTPS 打开 | 检查网址以 `https://` 开头，且证书已生效。                          |
| 打开的是文档站    | 使用仓库根目录和 `pnpm build` 重新部署。                            |
| 短信登录报 10004  | 改用扫码，或试填 `NETEASE_REAL_IP`（自己的国内公网 IP）后重新部署。 |
