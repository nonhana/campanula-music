# 产品概览

Campanula 是开源（MIT）的第三方网易云音乐 Web / PWA 播放器。听众用自己的网易云账号登录，打开即进入自己的曲库，围绕“听歌、搜歌、收藏歌”一条主线运转，去掉官方客户端的广告、社区、商城、推荐信息流、评论与 MV。

## 目标与原则

1. **打开就是曲库**：音乐和封面是主角；不推送、不打扰，界面不与封面抢注意力。
2. **照官方的行为，做得更轻**：交互行为沿用网易云官方客户端，完成度以 Spotify 网页版为底线（见 [ADR-0002](../adr/0002-netease-behavior-spotify-polish.md)）；偏离官方的交互必须经过验证。
3. **两种屏幕一视同仁**：手机和桌面共用同一套设计系统，差异只在布局和输入方式；不把桌面习惯硬塞给手机（如双击播放、仅悬停可见的按钮）。
4. **如实交代状态**：本机已有的数据立即显示；网络、同步、下载、版权与试听状态始终明确交代。

## 听众与运行环境

- **听众与站长**：以自部署为主（[ADR-0009](../adr/0009-self-hosted-instances.md)）。每个实例给部署它的站长自用，不限制谁登录自己的网易云账号。
- **支持平台**：
  - 手机：连得上 Google Play 的 Android Chrome（安装为 WebAPK），装成应用后锁定竖屏，支持后台/锁屏播放与通知栏切歌；不考虑 iOS。
  - 桌面：Chrome 与 Edge（安装为独立窗口），支持键盘快捷键、右键菜单、鼠标悬停。
  - 响应式与输入方式：不做平板专属布局；`< 768px` 用手机布局，`≥ 768px` 用桌面布局；菜单形态等操作细节按输入方式（触屏 vs 鼠标）切换，而非只看宽度。
- **曲库内容特征**：听众常听日系 ACG、VOCALOID、日本流行及华语/欧美，封面多为高饱和插画；歌名、歌手名大量混排日文假名、英文、繁体与简体中文，且常有超长标题。
- **部署与网络**：
  - 首推 Vercel（函数地区 `hkg1`），也支持自建服务器通过 Docker 或 Node 部署。
  - 生产实例必须使用 HTTPS（Service Worker、Storage API、Web Locks、PWA 安装均要求安全上下文）。
  - 断网时可打开应用外壳、浏览本机曲库副本、播放已下载歌曲；未下载歌曲不可播。
  - 未登录时仅可见登录页（无介绍或示例曲库）和本设备的已下载歌曲。登录方式：手机默认短信验证码，桌面默认扫码，两者可互切。

## 功能范围

- **曲库**（本地优先，[ADR-0007](../adr/0007-local-first-library.md)）：包含我喜欢的音乐（手机标签显示“我喜欢”，页标题为“我喜欢的音乐”）、自建歌单、收藏的歌单、专辑与歌手；打开即显示本机副本并在后台增量同步，大歌单歌单内搜索在本地即时完成。
- **发现**：仅保留每日推荐作为入口，不做首页推荐流。
- **搜索**：支持单曲、歌单、歌手、专辑四类结果及输入建议；搜索历史仅存本机，不做热搜榜；提供歌手页（歌曲 / 专辑 / 简介）与专辑页（曲目 / 简介）。
- **播放**：播放队列、在线音质选择、列表循环 / 单曲循环 / 随机播放；歌词优先逐字、无逐字则逐行，翻译与音译独立开关；系统媒体会话（锁屏/通知栏控件）；听歌打卡。无版权歌曲置灰不可播；非会员遇到会员歌仅播试听片段并标“试听”。
- **收藏与歌单编辑**：红心（单首切换）、加入歌单（选我喜欢的音乐等同于红心）、收藏歌单/专辑/歌手；自建歌单支持新建、删除、改名与简介、选择网易云固定标签（上限 3 个）、裁剪上传正方形 JPEG 封面、隐私改公开（不可逆）、加歌删歌、多选与拖动排序、自建歌单间排序。我喜欢的音乐不可改名/删除、支持排序、多选无移除。
- **下载与导出**（[ADR-0006](../adr/0006-downloads-are-permanent-and-device-owned.md)、[ADR-0014](../adr/0014-export-copies-downloads-to-a-picked-folder.md)、[ADR-0017](../adr/0017-downloads-run-in-the-page-not-background-fetch.md)）：支持单曲、整张歌单、整张专辑下载；下载音频归属设备、永久可播，与登录及会员状态解耦；页面内下载并保留断点、重开自动续传；支持按歌单删除、一键清空、独立下载音质与带元数据的文件夹导出。试听片段不可下载。
- **PWA 底线**（[ADR-0015](../adr/0015-pwa-shell-cache-and-offline.md)）：可安装；后台与锁屏不断播（[ADR-0010](../adr/0010-two-audio-elements-hand-over.md)）；重开恢复播放队列与进度；断网可打开外壳并明确提示离线；新版本延迟到下次打开时生效，不打断播放。

## 明确不做

私人 FM、推送通知、排行榜、歌单广场、最近播放、评论、MV / 视频、播客、云盘、关注 / 动态 / 私信、商城、热搜榜、均衡器与音效、无缝播放与淡入淡出、定时关闭、桌面歌词、深色模式（[ADR-0008](../adr/0008-light-theme-only.md)）、多语言（仅简体中文）。

## 品牌与无障碍底线

- **品牌**：名称 Campanula，官网与文档域名 `campanula.caelum.moe`；品牌语言为纯粹、简单、优雅；Logo 为 Lucide 四瓣花（薄荷叶绿描边，`src/lib/components/svg/Logo.svelte`），不常驻旋转；视觉色板以 `uno.palette.mts` 为唯一源头，仅浅色主题（`<meta name="color-scheme" content="only light">`）。
- **无障碍底线**：WCAG 2.2 AA；全键盘可达、焦点环清晰、加载/空/出错状态齐全、返回页面恢复滚动位置；移动端点击目标足够大且无悬停专属操作；中日英繁简混排按 `lang` 切换字体，不出现字体回退空隙。
