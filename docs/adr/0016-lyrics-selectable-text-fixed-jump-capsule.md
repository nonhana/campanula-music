# 歌词的字能选，跳到某一句用固定在当前行那条线上的胶囊，当前行用两层宽度

作者 2026-10-28 在 PC 上用播放页歌词时报了三件事（#80）：不能按住鼠标拖动歌词；点歌词会直接跳过去，可很多时候只想选一段复制；当前行放大后会换行，把布局挤乱。按 ADR-0002，交互照网易云官方客户端：网易云桌面版的歌词能选字，跳转是右边一个“▶ 03:10”胶囊。作者同日在本地试了几版以后定下这几条（样子见 DESIGN.md 的 Lyrics）。

## 决定

- **字能选，桌面点歌词不跳。** 行不再是按钮。逐字点亮的那层不能选（`user-select: none`），复制只得到原文。选着字时不跟着当前行走，取消选中后下一次换行再跟。触屏在哪种布局都是轻点一行跳过去，手机布局用鼠标点也是。
- **跳转是一个胶囊，固定在当前行停的那条线上（38%）。** 只在听众自己滚歌词（滚轮、触控板、手指划、键盘）以后出现，停手 1 秒收起；写停在这条线上的那一句从几分几秒开始。滚动时胶囊不动，只换时间。点它只是把播放时间改到那一句开头，歌词再跟着播放时间回到当前行：滚到哪一句只决定跳到几秒，不直接决定歌词停在哪。
- **当前行用两层宽度，不多换一行。** 其他行 20/28 在窄宽里换行，当前行 28/36 用长宽，长宽正好是窄宽的 28/20 倍：放大后断在同一个字上，只多出行高。胶囊放在长宽右边，永远不压字。
- **播放页加宽，把空间让给歌词。** 整页最宽从 1240px 改成 1440px；1024px 及以上左列和封面一样宽（320–420px），窗口矮、封面被压小时左列跟着变窄。封面大小不变。
- **歌词仍不显示滚动条，也不做按住歌词拖动。** 只用滚轮、触控板、键盘滚。DESIGN.md 原来“歌词不显示滚动条”的规则不变，ADR-0012 给歌词留的例外也不变。
- **当前行停的位置只由播放时间决定。** 播放时间 → 当前行 → 滚到哪。量位置时按字号过渡走完以后的排版算（Web Animations 把正在进行的字号、行高、宽度过渡拨到终点，量完拨回，同一帧里，看不到）：同一行不论在换行那一刻、停手 3 秒后还是开关翻译时去量，都是同一个位置。

## Considered Options

- **每行一个胶囊，当前行常驻、其他行悬停出现**（#80 原方案）：滚动和移动鼠标时胶囊跟着一行行跳，作者试用后认为难看；常驻的胶囊还和长的当前行重叠。
- **当前行不换行，向右溢出到页面留白，右边缘淡出**（#80 原方案）：胶囊约 70px 宽，借出的留白只有 32 / 48px，长一点的当前行就从胶囊底下穿过；1024px 宽时约 15 个字就碰到，768px 宽时多数行都会碰到。
- **胶囊跟着当前行文字的末尾走**：长行会把胶囊推出视口，或者停在右边照样重叠。
- **按宽度缩小当前行的字号**：作者不要按宽度计算字号。
- **歌词区用自绘滚动条（只在鼠标靠近右边、拖动、点轨道时出现，自动跟随时不闪）**：已经做出来试过，作者决定歌词区彻底不要滚动条。
- **按住歌词拖动、横向滚动、跑马灯**：不做。

## Consequences

- 桌面普通行比原来窄：按 20px 汉字算，1440×900 一行约 28 字，1024×768 约 16 字，768 宽约 10 字。加宽播放页、左列跟着封面以后，宽屏和矮窗口拿回了一部分。
- 用鼠标跳到某一句要先滚一下：只是悬停，胶囊不出现。
- 键盘的 Tab 顺序不再是一行一个停点：先到歌词区（方向键滚，胶囊跟着出现），再到胶囊，Enter 从停在那条线上的那一句开始放。
- 换行时测出来的位置不再差 8px：以前当前行停在 38% 那条线上方 8px，听众滚开、停手 3 秒回来时再挪 8px，看起来像“回落”。
- 手机布局不变：轻点一行跳过去、长按选字、当前行 20/28 可以换行。
