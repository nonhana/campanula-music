# 按证据分层测试，独立采集 SSR 并保留未运行源码

2026-11-15 作者在 Spec #96 和 #97 决定保留既有听众行为测试，增加受控浏览器旅程、a11y 与候选产物验证。产品仍使用 ADR-0004/0013/0018 的同一 App、HTTP 路由和直接 SDK 调用。

## 决策

- 测试实现、配置、场景、录制、专用工具和报告归 `tests/`；人工开发的统一启动入口归 `scripts/dev.mts`，测试从 `_kit` 转出共享接口，细则见 ADR-0020。包脚本和 CI 只调用薄入口，Vitest 与 runner 复用同一份套件选择。已有浏览器 / 录制脚本随后续调用者迁移，开发 mock 插件与可写曲库已移到 `tests/_kit/mock`，独立根和双 HTTPS 见 ADR-0020。
- 纯规则归 `unit`；从 App 经过真实本机 HTTP 的行为归 `behavior`；消费者合同、录制与 mock 自检归 `contract`，明确区分各自证据；环境与候选产物归 `delivery`。World、Device 和 listener 共用 `_kit`。可运行命令随套件落地公布，空选择和缺少必需文件必须失败。
- 从开工提交保存用例全名、原结果和路径映射，默认全量回归逐项核对；新增断言另外列出。迁移不能以总数相近代替逐项对应。
- 产品覆盖率保留全部 `src` TS / Svelte、排除声明，与测试基建分开。独立 Vite SSR 从同一次 V8 快照收集，按执行时的源码映射转换和合并，并用已请求 / 未请求路由校准。浏览器没有采集的数据明确标出，不能用 SSR 或 App 替身当成 UI 证据。
- 浏览器旅程和 axe 在自行启动的受控环境运行；作者照清单验收、reviewer 读 diff 的交付方式继续保留。真实账号、Android 系统与真实读屏仍由作者验收。

## Consequences

运行入口和证据边界见 `tests/README.md`。目录迁移、修正漏采和新增断言的覆盖率变化分别报告，阈值以校准后的分区基线为据。原“不做界面自动化测试”的决定由 Spec #96 更新，尚未实现的浏览器和产物套件不发布空跑入口。

环境隔离将 mock HTTP 放入独立子进程后，子进程也保存真实 V8 脚本与当次映射，同一轮合并。报告按运行独占目录；迁移前文件集合由路径表继续执行原 src 阈值，当前 src 与产品分区另列，原阈值数值不降低。
