# CSS 变量驱动的可切换皮肤系统

皮肤被定位为产品的一等公民：一套完整可切换的视觉令牌集（颜色、字体、圆角、阴影），默认皮肤是现有 uno.config.ts 的薄荷绿/蜜桃粉浅色方案，未来按需追加新皮肤。决策：uno.config.ts 的主题色改为引用 CSS 变量（`rgb(var(--skin-*) / <alpha-value>)`），保留现有 `bg-primary/50`、`text-primary-900` 等写法的透明度与色阶语义；每套皮肤是一组 `[data-skin='...']` 作用域下的令牌 CSS，运行时切换、即时生效、零构建变体。

考虑过：构建期多主题（为每套皮肤生成独立样式表，切换时替换 `<link>`）——令牌在两套皮肤间割裂、切换需要加载样式，否决。代价：现有代码中所有硬编码颜色必须迁移进令牌（含 uno.config 的 shortcut 与 preflight），这是皮肤骨架的主体工作量；切肤偏好存入 localStorage。
