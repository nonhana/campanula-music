# 曲库数据本地优先：浏览器里存一份副本，后台与网易云增量同步

听众的曲库数据（歌单列表、每张歌单的曲目、歌曲信息、红心状态）保存在浏览器的 IndexedDB 里。打开 App 时先显示本地副本，再在后台与网易云比对，只同步有变化的部分；冲突时以网易云为准。红心、加入歌单、编辑歌单等写操作先改本地副本、立即生效，再提交给网易云，失败则回滚。这样一次解决三个问题：服务器在境外带来的跨境延迟、大歌单内搜索（全部在本地完成）、断网时浏览曲库。

## Considered Options

- **每次现拉**：最简单，但每一页都要等跨境往返；大歌单内搜索必须先拉完整张歌单，这正是前两次“搜第 4000 多首要等很久”的根源。

## Consequences

- 本地副本是网易云账号的私人数据（例如隐私歌单）：主动退出登录时删除，换账号登录时不沿用。属于设备、退出也保留的只有下载（ADR-0006）。
- 后台同步和听众的前台操作共用 hana-music-api 每个身份每秒 2 次的上游配额，同步必须给前台操作让路，否则前台请求会排队超时。
