# 下载的歌永久可播，属于设备，与登录无关

Campanula 下载的是在线播放用的同一份音频（普通 MP3/FLAC，不是官方客户端的加密 `.ncm`），连同封面、歌词和歌曲信息一起保存，断网或未登录时也完整可用。下载完成后不再复核会员权益：会员过期、歌曲下架、版权变化都不影响已下载的歌。下载也与登录无关：退出登录、换账号都不删除；未登录时同样可以浏览、搜索、播放和删除这台设备上的下载；在这台设备上登录的任何网易云账号都能看到它们。只有听众手动删除，下载才会消失。这是对 ADR-0002（行为以官方为准）的有意偏离：官方客户端里，会员下载的歌在会员过期后不能播放；而作者希望 Campanula 像本地播放器一样，“下载完就是下载完了”。

## Consequences

- 与官方客户端的会员权益规则不一致；作为开源项目，存在被版权方投诉的风险。
- 不涉及 `.ncm`：下载的音频本来就是普通格式，不需要解密。
- 未登录的听众也有一块可用的界面（已下载的歌曲），这是 ADR-0009“未登录只能看到介绍和登录入口”的唯一例外。
- 未登录时播放已下载的歌不做听歌打卡：没有账号可记，也不能补记给之后登录的账号，那可能是另一个人。
- 还在排队的下载也属于设备：退出或换了账号，排队的下载留着，谁登录就用谁的账号去取下载地址；新账号拿不到完整音频的歌（例如非会员遇到会员歌），标失败并说明原因（逻辑原型规则⑧）。
