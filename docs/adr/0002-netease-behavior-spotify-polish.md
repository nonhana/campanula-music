# 交互行为以网易云官方客户端为准，完成度以 Spotify 网页版为底线

听众都是网易云用户。Campanula 作为“轻量版网易云”，行为规则（点歌后播放队列怎么变、红心、下一首播放等）沿用网易云官方客户端，以符合听众已有的使用习惯；键盘操作、焦点、加载/空/出错状态、返回页面时恢复滚动位置等完成度，以 Spotify 网页版为底线。偏离这两个参照的交互，必须先经原型验证再落地。

桌面布局以原来的 Campanula 为蓝本，但蓝本只决定骨架和外观；它和官方客户端的交互行为冲突时，以官方为准。例如原来的桌面搜索是居中弹窗，改为官方的顶栏搜索框加结果页（视觉原型确认，2026-10-07）。
