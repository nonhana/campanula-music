# 公共实例：听众登录自己的网易云账号后使用，不做游客模式

Campanula 只运营一个官方实例 campanula.caelum.moe：听众登录自己的网易云账号后才能使用，未登录时只能看到介绍、登录入口，以及这台设备上已下载的歌曲（见 ADR-0006）。不设准入名单或邀请码，谁登录都能用；第一阶段按小圈子的规模设计，只是不对外宣传。hana-music-api 的上游配额由整个进程共享且不可配置（每个上游域名每秒 4 次、每个身份每秒 2 次），所以规模扩大之前要先在 hana-music-api 侧解决。第一期不把自部署当作支持场景：代码开源，但不为第三方部署提供文档或兼容承诺。

## Considered Options

- **只给站长自己用**：最简单，但违背“给别人用”的初衷。
- **以开源自部署为主**：普通人在安装之前得先学会部署。
- **免登录游客模式**：未登录时上游对大多数歌曲不返回播放地址，而且所有游客共用一个游客身份，体验注定很差。
- **准入名单或邀请码**：能防止陌生人挤占配额，但站长不想给小圈子设门槛。
