## 实现与边界

首页沿用作者选定的介绍与真实界面并排方案，手机先介绍，再自然滚动到播放器。顶栏 GitHub、部署旁的「查看项目源码」、第二步指南、真实 Brand、共享控件与原生阅读转场保留。文字外链沿用 `external-link-space` 与链接的 `::after`，内部为普通文本流，下划线连续；站外 HTTP(S) 链接使用 `_blank` 与 `external noopener`，站内阅读保持原页。首页介绍写清第三方网易云播放器、自己部署与自己账号，以及只有已经下载到这台设备的歌才能离线听。大标题沿用已认可原型的比例，字号归入根 UnoCSS 的 Display，字重使用 600；其余文字使用已有阶梯。

`docs:dev` / `docs:build` 先构建 `website/demo/` 的独立 SvelteKit 入口，再运行 Astro；静态输出先写入被 Git 忽略的 `website/public/demo/`，最终随网站进入 `website/dist/`。Kit 生成目录是 `website/demo/.kit/`，路由、HTML 模板、静态目标和生成的 `$app` 类型均与播放器分开。静态适配只使用 Kit 的 `writeClient` 和 `generateFallback`，为 `/demo/`、`/demo/playlists/` 和两张示例歌单的允许深链输出入口，不输出 API 或服务端程序。不复制旧原型，不改写源码字符串，不提交 bundle，不依赖 `_notes/`、兄弟仓库、凭据或常驻后端。

示例在自己的 layout 装配真实 `createApp`，用真实本机数据库接口预装完整曲库及暂停队列，通过真实 App 读取曲目、打开歌单和播放。界面复用实际的 DesktopShell / PhoneShell、PlaylistTile、SongList、PlayerLayer、歌词、翻译、队列、波浪进度、封面染底与换碟。首页 iframe 与单独打开使用同一个静态入口，初始不调用播放；嵌入播放页使用非模态区域，不自动聚焦且允许 Tab 离开。独立播放页保留应用本来的模态键盘行为。桌面播放页内部控制行的 header 明确使用 presentation 语义，避免嵌入时误成为 banner 地标。

示例数据库分别是 `campanula-website-demo-v1:embedded` / `:standalone`，锁和 BroadcastChannel 也加同一前缀。`createApp` 可显式接收数据库，原实例仍默认打开 `campanula`，版本和数据格式未改；实例的 Cookie、账号、API、SW 和缓存策略不变。示例不创建 Cache Storage、不注册 SW、不提供 manifest。本地 `sampleFetch` 只返回固定示例，未知接口拒绝，异源路径拒绝，从不把 API 转成网络请求；实际音频、封面和字体均为本站文件。登录令牌、下载、目录选择、上传等未开放能力明确失败，示例标记隐藏红心、更多菜单、署名导航和右键业务菜单。队列和播放设置只改变示例自己的存储。

首页首次渲染预留播放器大小；未就绪时显示真实截图，关闭 JS 时保留图片、介绍、部署入口和指南。媒体失败时仍可看截图与说明。独立 demo 的 HTML 同样自带静态备用界面，应用脚本加载失败、无 JS 或媒体失败都能看到；单独打开时任一音频失败，先暂停本次示例创建的所有 Audio，再展示备用界面，防止预加载下一首失败后当前歌仍响却无法暂停。备用界面的指南出口明确放行。离开首页会卸下 iframe；iframe 的 pagehide 对两只真实 Audio 调用 pause 并清除源，浏览器返回重新打开暂停示例，不保持全站播放。

## 作者可以亲手试的短路径

优先人工项：实际扬声器的音色和音量、自己的手机触感、文字与封面观感，以及 axe 无法自动判定的染底文字对比度。自动浏览器的手机视口和可信触摸事件不代表真 Android、系统返回或真实读屏。

1. 打开 `http://127.0.0.1:4322/`。桌面应是左介绍右真实界面，手机先看到介绍，向下滚到播放器。部署旁应有「查看项目源码」，顶栏保留 GitHub 图标。刚打开应安静，焦点不会跳进播放器；图片被挡住、标题拆字或自动响都不对。
2. 点播放，点下一首，再看歌词与翻译、打开播放队列。点「收起播放页」，应回示例曲库；打开歌单，点另一首，应播放那首。手机先将播放器滚到方便操作的位置。
3. 正在放时点首页「部署 Campanula」，应进入指南并停止本页声音。回首页应是暂停的示例。想一边读一边听，可以先「单独打开」，声音只属于那个独立页面。
4. 可选键盘：Tab 进播放器，从最后一个控件继续 Tab，应到外面的「单独打开」；可选关闭 JS 或阻断音频，截图、说明与部署入口应保留。直接刷新 `http://127.0.0.1:4322/demo/playlists/502/` 应仍能看到三首示例歌。
