# 布局、页面结构与骨架防跳动

## 断点与输入方式

- **视口断点**：`< 768px` 为手机布局，`≥ 768px` 为桌面布局；不做平板专属布局。
- **输入方式独立于宽度**：菜单形态（鼠标右键/浮动菜单 vs 触屏底部弹层）、是否显示音量等按输入方式切换，窄窗口里用鼠标仍保留右键菜单。
- **悬停限定**：悬停样式只给鼠标/触控板，UnoCSS 统一用 `mouse:hover:`（`@media (hover: hover) and (pointer: fine)`）。

## 桌面与手机骨架

### 桌面骨架

- **顶栏（64px，固定在晨光底上）**：菜单键、Logo、返回/前进按钮、窗口居中搜索框（最宽 560px，左侧空间不足时右让而不压窄）、头像。
- **侧栏**：收起 72px 图标栏（曲库、每日推荐、已下载，设置贴底），点击菜单键展开为 220px 带文字侧栏，内容区同步让位。
- **内容区**：最大宽 1280px，左右内边距 32px；底部通栏播放条 80px。

### 手机骨架与返回栏

- **首页**：Logo 行（右侧搜索、每日推荐日历按钮）、吸顶文字标签行（我喜欢 / 歌单 / 专辑 / 歌手）、首次同步细条、56px 高无分隔线 Auxio 式歌曲行、底部离边 8px 的 64px 浮起迷你播放条（下方垫一层晨光渐隐）。
- **二级页返回栏**：歌单、专辑、歌手、每日推荐、已下载五类页面平时只显示 `←`，不写类别词；当页头 `<h1>` 整行滚到返回栏下方后，`←` 右侧淡入单行截断页名（`aria-hidden`，保留原 `lang`，进 200ms / 出 120ms；恢复滚动位置时直接到位）。设置页无 `<h1>`，返回栏常驻“设置”。

## 核心页面结构

### 桌面首页

首页只作曲库目录，区块间距 40px：

1. 首次同步条（仅首次同步未完成时出现）
2. **我喜欢的音乐**（白色面板内三行横向歌曲格，一屏 3.25 列，末半列渐隐）+ 右侧 280px **每日推荐**方块（`< 1280px` 时每日推荐排至歌曲格下方横条）
3. **自建歌单** → **收藏的歌单** → **专辑** → **歌手**：各占一个横向架子，展示全部条目，支持横向滚动与鼠标拖着滚。标题行：`Title 600` + 数量（`Caption` 石墨淡等宽数字）+ 右侧“查看全部”（自建前多一个“新建歌单”Outline 胶囊；空类不显“查看全部”）。返回首页时恢复各架子横向位置。

### 曲库的歌单 / 专辑 / 歌手页

- 桌面经首页“查看全部”进入，手机对应曲库标签页。
- 右侧（手机在标签下方）设本地筛选框（`SearchField`，桌面最宽 280px，“筛选歌单 / 筛选专辑 / 筛选歌手”）：纯本地筛选、断网可用，忽略大小写与全角半角（歌单按名、专辑按名+歌手、歌手按名），保留原序；筛中时标题数量切为“找到 N 张 / 位”，歌单页无命中分区收起，全无命中显示 `SearchX` 空状态。返回时筛选词与滚动位置同步恢复。

### 详情页头（`library/DetailHeader.svelte`）

歌单、专辑、歌手、每日推荐、已下载统一复用：

- 封面桌面 200px、手机 168px；标题 `line-clamp-2` + `break-words`；信息行不写“歌单 / 专辑 / 歌手”类别词（创建者前配 20px 圆头像，不链接）。
- 歌单与专辑的简介在页头仅放预览（`library/DescriptionPreview.svelte`）：桌面在标签/信息行下 8px 放单行文字，手机在动作行下 16px 放两行白色卡片；溢出的整行/整卡可点开简介阅读层（`aria-label="查看简介"`），放得下则为纯文字。
- **桌面动作行**：单行不换行工具栏，左动作右搜索（搜索 280px 可缩至 128px）。按工具栏自身宽度（约 500px）切紧凑态：紧凑时自建歌单的“添加歌曲”收进 `•••`，收藏歌单的“下载”缩成蜜桃图标、保留“收藏”。
- **操作分档**：主操作（播放全部）实心胶囊、页面级次级（下载 / 收藏）带字胶囊（手机收藏仅图标，`aria-pressed`）、管理类（添加歌曲 / `•••`）图标簇；多选入口不在页头，而在列表表头最右。

### 桌面歌单页与目录左栏

- 曲库内歌单为两栏（`< 1024px` 收起左栏）；不在曲库里的歌单为单栏（收藏后切两栏，取消收藏切回单栏）。
- **左栏（208px）**：一行一张 56px（40px 封面 + 歌单名 + 首数，隐私歌单带锁），顶置“我喜欢的音乐”，下分“自建歌单”与“收藏的歌单”两块（空块隐藏）。当前项薄荷玻璃底森林墨字，正在播放来源项右侧显三根小竖条。上下边缘 40px 渐隐（有溢出时生效），初开定位正中，左栏内切换若已完整露出则不滚、且不触发封面飞行。

### 歌手页

- 页头居中（圆头像、名字、“N 首歌 · N 张专辑”、播放全部、收藏）。
- 下方吸顶标签行：**歌曲 / 专辑 / 简介**（共用 `ui/Tabs.svelte`，状态写入 `?tab=` / `?order=`，替换历史不增记录；下方内容至少一屏高以保持吸顶）。
- **歌曲标签**：每次 100 首 + 面板外居中 `ui/ShowMore`，带多选；吸顶标签行最右放文字分段 `热门 | 最新`（两种排序各自保留已加载列表）。
- **简介标签**：使用 `ui/LongText.svelte`（行高 28px，保留换行、`break-words`、按段带 `lang`）；桌面白色面板最宽 768px 居中，手机左右 16px 卡片。

### 格子网格（`library/TileGrid.svelte`）

格宽与骨架数量统一由 `library/tile-grid.ts` 决定：

- 桌面网格：歌单/专辑 176px、歌手 128px（骨架 6）；手机网格：歌单/专辑两列（骨架 4）、歌手三列（骨架 6）。
- 横向架子：桌面歌单/专辑 168px（骨架 7）、歌手 120px（骨架 9）；手机搜索架子：歌单/专辑 140px（骨架 3）、歌手 104px（骨架 4）；搜索综合歌单排为 6/5/4 列。
- 仅搜索结果网格展示收藏角标（右下角始终可见的 32px 白色小圆钮，与链接并排不嵌套）或“自建”标记；曲库与歌手页网格不画收藏角标。

### 搜索结果

- **桌面**：顶栏搜索框挂无遮罩下拉（历史与建议，建议按左侧类别图标区分，无热搜）；提交后进入内容区结果页，吸顶标签为 **综合 / 单曲 / 歌单 / 歌手 / 专辑**（后四项旁显示总数，不重复写在区块标题）。
- **综合**：四块各自独立加载/骨架/报错重试，空块隐藏，全空提示“没有找到”。单曲前 5 首无多选，其余三块为横排/架子。
- **四标签**：每次 30 条 + 面板外居中 `ui/ShowMore`；桌面歌单为 64px 列表行，歌手与专辑为网格。

### 歌单增删改、排序、多选、换封面与设置

- **自建歌单管理**：头部 `ListPlus`（添加歌曲）+ `•••`（编辑歌单信息、隐私改公开、删除歌单）；编辑弹窗名称上限 40 宽度（汉字计 2），简介上限 1000 字，标签限选 3 个。新建等待远端返回后关窗；编辑、改公开、删除即时关闭并乐观更新，失败回滚提示。在歌单页删除先退回曲库再删。
- **自建歌单排序**：仅在曲库歌单页（桌面保持封面网格、右上角淡入把手；手机自建区原地切换 56px 带把手列表，与旧网格叠同一格平滑变高变矮）；我喜欢的音乐与收藏歌单不参与。支持 `Alt + ↑ / ↓`、`Esc` 取消。
- **多选**：覆盖所有歌曲列表（除搜索综合前 5 首、播放队列、挑歌弹窗）。入口在桌面表头最右 32px 圆钮 / 手机数量行右侧 `ListChecks`，也支持 `⌘/Ctrl` 点选、`Shift` 连选、手机长按。进入后表头换为吸顶工具条（不透明晨光底、无阴影）；可用动作统一定义在 `library/selection-actions.svelte.ts`，调用方按需选用。
- **下载整张**：歌单与专辑页头“下载”打开挑歌弹窗（桌面 560px，定高最高 800px），默认勾选可下载项，禁用并写明已下载/排队/试听/无版权，底部汇总“已选 N 首 · 共约 X MB”。
- **换封面**：编辑弹窗内点封面进入（桌面 620px 居中弹窗，手机全屏），裁剪支持单指拖、双指捏合、滚轮、滑块与方向键；提交后保留只读预览与一处忙碌态，不展示内部步骤。
- **设置页**：单栏最宽 640px 居中，分账号、在线播放音质（5 格分段条，“从下一首开始生效”）、下载（独立音质分段条、已用空间与清空、“已下载”入口行）。
- **已下载页**：页头有“播放全部”与 `•••`“下载管理”（仅含“按歌单删除下载”）；页头与歌曲列表之间在有任务时显示“正在下载”（共用 `DownloadTaskRow`），未登录同样支持浏览、播放、多选导出/删除。

## 骨架与内容防跳动

骨架切换为内容时必须与真实排版重合，不引起周围常驻元素位移：

- **同形骨架**：各类歌曲行（桌面、手机 Auxio、手机带序专辑、挑歌勾选行）统一在 `songs/SkeletonRows.svelte`；首页我喜欢的音乐采用同套 3.25 列格子骨架；网格与架子由 `TileGrid` 共用外框；挑歌弹窗桌面定高（最高 800px），计数行加载中固定 20px；歌词骨架顶含开关行并从 38% 线起排。
- **常驻元素先占位**：手机数量行（“N 首”放短骨架）、首页四排“查看全部”占位、搜索标签旁总数短骨架、歌单页“下载”按钮（禁用态占位）、详情页头动作行（手机 44px 胶囊）。
- **按需数据不占位**：歌单标签、简介预览、两行折行标题等仅在数据到达后随骨架交叉淡化一起出现。

## 滚动与“定位到正在播放”

- 页面使用浏览器原生窗口滚动，局部区域各自 `overflow: auto`，系统滚动条全部隐藏并换为自绘悬浮滚动条（[ADR-0012](../adr/0012-native-scroll-custom-scrollbar.md)）。顶栏下设 `scroll-padding-top`（顶栏高 + 8px）防止键盘焦点被遮挡。
- **初开直达、主动平滑**：打开歌单左栏或播放队列定位当前项时直接到位；点击定位按钮、点当前标签回顶、歌曲格翻页、前进后退定位左栏用平滑滚动（减少动态效果时直达）。
- **定位到正在播放**：播放队列和所有歌曲列表（不含搜索综合前 5 首、挑歌弹窗）自带。当正在播放行在本列表内、未完整露出视口且未处多选/拖排时，右下角淡入 40px 白色圆钮（点击区 44px，`LocateFixed`，200ms/120ms）。点击后滚至该行停在第二行（首行停第一行；距离超 3 屏先跳至 1 屏外再平滑滚完），滚完聚焦该行。
- **z-index 层级**：内容 < 页面定位按钮 < 下载面板（30）< 播放条 & 桌面播放队列面板（40）< 提示条（50）< 菜单（60）< 弹窗（70）。
