# 文案、状态块、按钮层级与图标词典

## 文案铁律

字越少，封面与歌曲越显眼。界面只写听众此刻必须知道、且无法从图标或控件状态看出的信息：

1. **一件事说一次**：标题说清了就不写正文；按钮写着“重试”，正文就不写“再试”。列表或控件已有直接反馈时不再弹成功提示，自动恢复类过程不单独播报。
2. **下一步交给按钮**：屏幕上有明确操作按钮时，不写“点…”。
3. **看得见的不写**：优先用既有图标、数字、进度条、勾选和转圈表达状态；图标必须保留读屏名称（`aria-label` 或 `sr-only`），悬停提示不能替代名称和必要原因。不必要的信息直接删除，不塞进问号气泡或帮助入口。
4. **不讲机制**：不解释后台调度、内部上传步骤和常识性后果；只保留会改变听众当前决定的信息——不可逆后果、隐私与删除范围、真实失败原因、不可见生效时机（如音质“从下一首开始生效”）、离线能力边界、结果不完整。危险范围只在确认弹窗交代一次。
5. **报错一句话**：格式为“没能 + 动作：原因短语”（标题已写“没能…”则正文只写原因）。原因短语统一由 `failure.ts` 的 `failureText` 提供，不带下一步与句号。“请告诉站长”仅用于打开 App 失败整页和无法重试的原因（如“Campanula 需要升级”）；唯一带下一步的是“操作太频繁，等一会儿再试”。
6. **进行中不换字**：等待回应的按钮按下后文字不变（不改成“正在…”），由左侧转圈与 `aria-busy` 表达忙碌。
7. **同词一屏不重复**：返回栏、页头、区块标题与信息行不重复同一类别词（方封面/圆头像已标明类型，信息行不写“歌单/专辑/歌手”）；数量除外。
8. **标点**：单句说明、报错、提示条不加句末句号；两句及以上正常加句号。

**例外**：未配置 HTTPS、未配置 `COOKIE_SECRET` 两张面向站长的整页完整写出配置步骤。

**提示条句式范例**：`已加入「poems」`、`已创建「…」`、`已把「…」改为公开`、`已删除「…」`、`已加入下一首播放 2 首`、`已开始播放`、`已红心《…》`、`已删除 2 首 · 保留 1 首`、`2 首下载失败`、`存储空间不够，下载已暂停`、`已从「…」移除 N 首`（配“撤销”）。批量下载仅汇总跳过数量与原因；正常加入和自动恢复不发提示。

## 空状态与出错状态（`ui/StateBlock.svelte`）

结构：一枚淡色圆图标（空态薄荷底，错态出错红感叹号）+ 一行 `title-sm` 标题 + 最多一个主动作按钮（出错为“重试”）。正文严格可选：标题已说清时不留空段，按钮照常隔 20px。加载中不使用 `StateBlock`，改用同形骨架。

## 按钮层级

胶囊形（`rounded-full`），按下轻缩 98%（`press`）。可见高度手机与桌面统一 40px，上下外扩 2px 保证 44px 点击区（`pill-hit`）；与输入框并排的按钮高 44px。图标按钮桌面 40px / 手机 44px（20px 图标）。

- **Primary**：深薄荷底白字 500，左 16px 右 20px、左侧带图标，悬停变森林墨（播放全部、登录、重试、非破坏性确认键）。
- **Download**：浅蜜桃底蜜桃木字，悬停加深一档（下载、保存二维码）。
- **Outline**：纸白底 1px 发丝线石墨深字，悬停薄荷线边框 + 极浅薄荷底；用于桌面次级操作（收藏/已收藏、排序、新建歌单、清空、取消）。列表表头最右多选圆钮例外为 32px 以适配 36px 表头。
- **Icon**：透明底石墨重图标，悬停薄荷雾底森林墨图标。
- **Text（`ui/TextButton.svelte`）**：无底无框，左右 12px、高 44px（桌面可 32–40px），分深薄荷（重试、撤销、完成、查看全部、全选）与石墨重（取消、清空）；起确认作用的用 600 字重。`desktop` 属性使其在桌面渲染为胶囊。
- **Destructive**：出错红底白字，仅用于删除歌单、删除/清空下载等破坏性确认键。
- **Disabled**：实心按钮变发丝线灰底石墨淡字；其余降为 50% 不透明度。
- **Busy（`busy` 属性）**：文字不变、不灰显、宽度不变，左侧图标位换为 16px 转圈（无图标则在字前预留位显示），设 `aria-disabled` + `aria-busy` 并拦截点击与回车提交，焦点留在按钮上；减少动态效果时转圈停住。

### 手机按钮四档判断（`< 768px`）

| 档位   | 外观                                                   | 使用场景                                                                                                  |
| ------ | ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------- |
| 主操作 | 实心胶囊（可见 40px / 点击 44px）                      | 每屏一个：播放全部、弹窗确认键、空/错态动作                                                               |
| 工具   | 纯图标（20px，点击 44×44，无底无框）                   | 与标题/数量/其他按钮并排且语义直观无高代价的次级操作（`ui/ToolButton.svelte`，桌面自动渲染 Outline 胶囊） |
| 文字   | `ui/TextButton.svelte`（点击高 44px）                  | 图标难直观表意或误点有代价：完成、重试、撤销、清空、查看全部、取消/保存、全选                             |
| 选择   | 分段条或 chip（36–40px）；与标签并排用文字分段（44px） | 选项本身即内容：音质、翻译/音译、标签、搜索历史、歌手页排序                                               |

**次级操作能否只留图标**：不与标题/数量并排（如列表尾“显示更多”）可留胶囊；若并排，图标公认且无误点代价（进模式、开弹层、可逆开关）留图标，有代价则用文字按钮或“图标 + 确认”（如退出登录）。

## 全站图标词典

全站统一使用 `@lucide/svelte`，每个图标固定唯一含义；新增动作图标须先补充下表：

| 图标                         | 唯一语义                                                        |
| ---------------------------- | --------------------------------------------------------------- |
| `Plus`                       | 新建（新建歌单、加入歌单内“新建歌单”）                          |
| `ListPlus`                   | 把歌放进歌单（添加歌曲、加入歌单）                              |
| `ListMinus`                  | 从歌单移除歌曲                                                  |
| `ListEnd` / `ListStart`      | 加入播放队列末尾 / 下一首播放                                   |
| `ListMusic`                  | 歌单本身（空/已删歌单、播放队列入口）                           |
| `CirclePlus` → `CircleCheck` | 收藏 / 已收藏（全站统一，已收藏深薄荷）                         |
| `ListChecks`                 | 多选                                                            |
| `CheckCheck` / `SquareMinus` | 全选 / 全不选                                                   |
| `ListX`                      | 清空播放队列                                                    |
| `Check`                      | 勾选、开启态（翻译/音译）、已完成步、成功提示；不作动作按钮图标 |
| `Clock`                      | 排队等待                                                        |
| `Pause`                      | 暂停（播放或下载）                                              |
| `ArrowUpDown`                | 排序                                                            |
| `Ellipsis`                   | 更多                                                            |
| `Trash2`                     | 删除（歌单、下载，出错红）                                      |
| `FolderDown`                 | 导出到文件夹                                                    |
| `FolderOpen`                 | 选择文件夹（导出确认键）                                        |
| `LogOut`                     | 退出登录                                                        |
| `X`                          | 关闭、移出单首、清除搜索词                                      |
| `LocateFixed`                | 定位到正在播放                                                  |
