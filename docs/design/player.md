# 播放界面与签名组件

## 播放页布局与抽屉

- **桌面播放页**：整页最宽 1440px 居中，背景为封面染底浅雾（[foundations.md](./foundations.md)）。顶栏左侧为收起键与来源、正中固定居中 **歌词 / 播放队列** 分段条（顶栏空白区支持下拉收起）。左列含封面（支持鼠标按住左右拖换碟）、歌名、歌手/专辑、波浪进度、控制键（含独立循环与随机开关）、音量；`≥ 1024px` 时左列与封面同宽（320–420px），矮窗时封面缩小连带收窄左列让位歌词，`< 1024px` 按比例分栏。右列均直接铺在封面染底上（无白卡）：歌词保持宽栏，切至播放队列时列表限宽 560px 且双栏通过纯位移（`translate`，360ms `ease-out-soft`）同步平移居中、分段条原地不动。
- **手机播放页**：单屏不滚动；控制行照网易云单排 5 键（左至右：单键轮换播放模式 / 上一首 / 72px 播放键 / 下一首 / 播放队列，两端 44px 图标按钮，下留 24px + 安全区）。播放模式列表循环仅图标，单曲循环/随机播放垫薄荷雾底森林墨图标。轻点封面切换歌词（封面缩 96% 淡出 200ms，歌词下浮 16px 360ms）。
- **音量策略**：触屏为主设备（手机、平板）音量恒为 100%，不读写本机音量且桌面条/播放页不画音量控件；桌面设备可调并持久化，默认 30%。
- **播放页抽屉**：自底升起/缩回 380ms，离顶露 24px 圆角，压暗底层曲库。桌面顶栏空白区与手机“正在播放”区支持下拉（触屏 10px / 鼠标 2px 起拖；过可见高度 1/4 或均速 > 0.4px/ms 收起），底栏/迷你条封面歌名区支持上拉展开。

## 播放条（Player Bars）

- **桌面底栏（80px）**：纸白浮起阴影，顶边 2px 薄荷进度滑块（16px 隐形点击带；悬停/聚焦/拖动加粗至 4px 显 4×14px 深薄荷游标，松手跳转，支持 `←/→` ±5 秒与 `Home`/`End`）。左：上一首 / 44px 森林墨圆播放键 / 下一首 + 时间；中：封面、歌名、歌手链接、右端心形键；右：播放模式、音量（非触屏）、播放队列按钮（开关右侧桌面播放队列面板，带 `aria-expanded`，开态薄荷玻璃底）。
- **手机迷你播放条（64px）**：纸白 16px 圆角浮起阴影，距屏幕边 8px；封面、歌名、歌手、心形键、44px 播放键、下一首，底边细进度线（只读）。
- **显现、播放键与清空时序**：首次入队 360ms 上浮，队列清空 200ms 下沉；播放/暂停图标 120ms 交叉淡化缩放，缓冲超 300ms 才淡入转圈；换歌后后台预取播放页大图（`prefetchPageCover`）；在播放页内点击“清空”须先收起播放页（及手机队列弹层），收完再清空队列与下沉播放条。

## 晨光行（Morning Row，签名组件）

- 正在播放行从歌名左边缘向右随播放进度铺开浅薄荷光（起点 16px 渐入、前沿 40px 渐隐）：白面板用薄荷雾，晨光底（手机）用薄荷玻璃，封面染底队列整行先垫薄荷玻璃、晨光用薄荷线。
- 封面中间压 28px 白圆片三竖条（暂停时停住），桌面序号列同步换为三竖条。换歌时旧行光 300ms 散去，新行光 200ms 淡入；减少动态效果时竖条静止、光随进度跳变。

## 波浪进度条（Wave Progress）

- 仅用于播放页（常驻播放条用平直 2px 线）。已播段为 3px 茎绿正弦波，未播段为平发丝线，游标为 4×18px 深薄荷圆角竖条，两端等宽数字时间。
- 仅播放时起伏流动；暂停或拖动时 160ms 抹平，恢复播放 420ms 渐起；是完整滑块（拖动、点跳、`←/→` ±5 秒、`Home`/`End`）。减少动态效果时不流动、起伏直切、游标约 250ms 跳动。

## 换碟转盘（Cover Wheel，签名动作）

- 轴心位于封面正下方 1.6 倍边长处，相邻封面夹角 28°；下一首逆时针左转、上一首顺时针右转，播放页 600ms、播放条小窗 480ms（`ease-out-soft`）。歌名/歌手/专辑晚 80ms 横向飘换（200ms/120ms），封面染底 700ms 交叉淡化，波浪进度 200ms 回收起点。
- 方向严格按 App 发布的 `PlayerState.change` 决定（随机模式也准确）；列表点歌由封面飞行进入播放条，恢复队列或单曲重播不转。
- **左右拖切歌**：手机与桌面播放页封面均支持横向拖动（横挪 6px 起拖跟随 `PlayerState.neighbors` 转入邻曲封面，松手过 1/4 格或甩速 > 1000px/s 即切歌并顺势转完，否则 240ms 回正；单曲队列可拖但总回正）。
- **打断与防白屏**：连切时直接从当前角度转向最新目标、跳过中间歌名与染底；转盘先铺已缓存小缩略图（`SMALL_COVER`），停稳后按序加载当前大图并 240ms 淡入，再到后台预载上下首大图。减少动态效果时原位 150ms 交叉淡化。

## 歌词（Lyrics，[ADR-0016](../adr/0016-lyrics-selectable-text-fixed-jump-capsule.md)）

- **逐字与状态**：双层文字叠放，上层 `user-select: none` 按唱到比例裁切点亮，复制仅得原文；无逐字时整行高亮，不显示“逐字/逐行”标签。当前行停在高度约 38% 处；译文、音译独立图标开关（`Languages` / `CaseSensitive`）固定于歌词区右下角纵向排列（桌面落在右侧跳转通道内不压字），开启态薄荷玻璃底森林墨图标，无则禁用并经 `title`/`aria-label` 说明“无翻译 / 无音译”；无词写“纯音乐”或“暂无歌词”；加载中用骨架，失败说明原因并可重试。
- **选字与防干扰**：桌面鼠标点击歌词只选字不跳转；选字期间不自动跟随滚动，取消选中后下次换行再跟；听众手动滚动后 3 秒内暂停跟随。触屏及手机布局轻点行即可跳转。
- **38% 固定跳转胶囊**：听众主动滚动歌词时，右侧 38% 基准线上淡入固定胶囊（`▶ 3:10`，高 36px、纸白发丝线、等宽数字、读屏“从 3:10 开始播放：+ 句文”），滚动仅变时间与对应句加深；点击从该句起播并让歌词跟回当前行；停手 1 秒淡出（鼠标停留或键盘聚焦胶囊时不淡出也不自动跟随）。键盘先 Tab 至歌词区（方向键滚），再 Tab 至胶囊。歌词区不显示滚动条，也不支持鼠标按住拖动滚动。
- **桌面双层宽度**：普通行 `20/28` 占窄宽，当前行 `28/36` 用长宽（正好为窄宽的 `28/20` 倍），确保放大不改变换行断点、仅增行高（300ms 过渡），滚动定位按过渡终态排版算，无二次抖动。

## 播放队列（Playback Queue）

- **三种形态**：
  1. **桌面播放页右栏**：与歌词并排在同一滑动轨道（360ms `ease-out-soft`，隐藏栏 `inert`，保留歌词滚动位），直接铺在封面染底上无白卡；切入前当前行已直达第二行，可见时换歌不打断听众手动滚动。
  2. **桌面播放队列面板**：由底栏队列键开关，固定右侧（距右 16px、顶栏+断网条下 16px、底距播放条 16px、宽 400px，纸白 16px 圆角浮起阴影，z-index 40 盖在下载面板之上）。属非模态浮层，不压暗、不占浏览记录；右侧 24px 360ms 飘入 / 200ms 飘出，打开聚焦当前行、关闭回焦队列键；点面板与播放条之外、Esc、换页、切手机布局、队列清空或拉播放页时自动收起；点击播放条常规控件不收起。
  3. **手机播放队列弹层**：由手机播放页控制行最右队列键打开，挂于播放页内独立 `100dvh` 抽屉容器，下拉把手或返回收起。
