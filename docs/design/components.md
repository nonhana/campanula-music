# 通用组件与交互模式

播放专属界面（晨光行、波浪进度条、播放条、换碟、歌词与播放队列）见 [player.md](./player.md)。

## Chips、分段条与徽标

- **Tag**：薄荷雾底、森林墨字、24px 高（歌单标签）。
- **Filter / History**：纸白底 + 发丝线、36px 高（标签库、搜索历史、歌词翻译/音译开关）；选中变薄荷玻璃底森林墨字，禁用降 50%。
- **Segmented（`ui/Segmented.svelte`）**：等宽晨光底轨道 + 薄荷玻璃滑块（换选滑块 `transform` 360ms `ease-out-soft`，字色 200ms），高 40px（音质 5 格，桌面最宽 400px）或 44px（登录方式、桌面播放页歌词/队列）。支持 `look='text'` 文字分段（歌手页“热门 | 最新”）：无轨道无滑块，Label 字（选墨色 600 / 余石墨淡 500），12px 发丝竖线分隔，每格高 44px。按语义分 `radiogroup`/`radio`（单选）与 `tablist`/`tab`（换面板），支持 `←/→`（单选含 `↑/↓`）、`Home`/`End`、Tab 只停在选中格。
- **Badges**：`micro` 11px 500 字重，跟在歌名后——试听（琥珀底琥珀字）、无版权与未下载（淡发丝底石墨重字）。

## 卡片、输入框与导航

- **卡片与容器**：白底无边框配环境光阴影，16px 圆角（面板）/ 12px（网格封面）；列表面板内边距 8px，每日推荐方块与弹窗 20–24px。
- **输入框**：纸白底 1px 发丝线，搜索框全圆角 44px（左搜索图标、有词右显清除键），表单框 12px 圆角；聚焦边框 2px 茎绿（白底 3.6:1）+ 外圈 3px 薄荷雾光环；出错配出错红边框与说明，禁用降 50%。
- **桌面侧栏**：72px 图标栏展开为 220px；展开时宽变 60ms 后文字 160ms 淡入，收起时文字先 120ms 淡出再 200ms 变窄。当前项 48px 高 12px 圆角薄荷玻璃底森林墨图标。
- **标签条（`ui/Tabs.svelte`）**：手机曲库标签、搜索结果、歌手页共用。选中墨色 600 + 底部 3px 薄荷短线滑移（360ms）；`tablist`/`tab`/`tabpanel` 键盘左右切换绕回、`Home`/`End`，Tab 只停当前项；溢出支持横向滚动。
- **已下载入口**：桌面在侧栏第三项；手机在设置页内；未登录/登录失效时登录页下方显示蜜桃入口（图标 + “已下载” + 首数 + 箭头），直达同一页面。
- **返回与前进**：桌面顶栏 Logo 右侧置 `ChevronLeft` / `ChevronRight`（照网易云/Spotify，不做面包屑），与手机返回栏 `←` 共用规则：按“页”跳过同一地址的浅路由记录，仅走本次打开以来的历史（避免刷新打断播放）；无上一页时首页禁用、其余页替换为曲库；无 Navigation API 时均禁用，禁用仍占位。

## 歌曲行（Song Row）

- **结构与交互**：高 56px，单击/轻点整行即播，绝不要求双击。桌面左序号、歌名+歌手、专辑、状态列（无表头字，心形+下载图标）、时长、常驻“更多”键；手机左封面、歌名+歌手、常驻“更多”键。桌面右键开同一菜单。
- **状态标记**：已下载（蜜桃枝）、下载中（蜜桃进度）、排队（`Clock`）、失败（出错红感叹号，可重试）；无版权及离线未下载整行降 45% 不透明度并配徽标。
- **桌面行内歌手 / 专辑链接**：桌面布局下的歌曲行、首页歌曲格、播放队列、播放条、播放页中，编号 > 0 且非指向当前页、非多选、非未登录的歌手名与专辑名可点击换页（多位歌手各自独立链接，悬停加下划线 `underline-offset-3` 变墨色，不飞封面、不放歌、右键仍出菜单）。列表行内链接不进 Tab 顺序（键盘/读屏走“更多”菜单）；播放条与播放页链接进 Tab 顺序；手机歌曲行/迷你条/队列不做行内链接。
- **更多菜单**：依次为下一首播放、加入播放队列、加入歌单、红心/取消红心、分隔线、下载（已下载页换红字“删除下载”）、导出（已下载且浏览器支持选文件夹时）、查看歌手（多位时原地转交歌手列表）、查看专辑。未登录时仅留播放、加入播放队列、导出、删除下载。
- **手机多选行**：与普通行保持 56px 高、左 16px、列距 14px，仅前增 22px 勾选框，尾端 `•••` 换拖动把手（可排歌单）或隐去；数量行恒 48px，进出多选不跳动。
- **点歌反馈**：桌面序号淡出、三根竖条长出（`NowIndex`），手机封面淡入 28px 白圆片竖条（200ms），歌名变森林墨；该行封面沿浅弧飞入播放条（480ms），首次点歌播放条先 360ms 上浮；快点多首只飞最后一首。

## 浮层与弹窗（Overlays & `DialogShell`）

浮层栈历史策略、转交与焦点循环契约见 [docs/agents/overlay.md](../agents/overlay.md)。

- **浮动菜单 / 搜索下拉**：从锚点侧 4px 外 98% 大小 200ms 飘出，关闭 120ms 淡出。搜索历史为有名称的非模态弹层，输入框 `aria-expanded` / `aria-controls` 准确绑定，Tab 可离开、Esc 收起回焦输入框。
- **弹窗外壳（`DialogShell.svelte`）**：遮罩 200ms 淡入，弹窗从下 8px 98% 360ms 飘入、200ms 淡出。桌面居中四档宽度：确认 `440px`、表单 `480px`、挑歌 `560px`（定高最高 `800px`）、编辑信息与简介阅读层 `680px`；手机底部弹层（确认贴底、阅读最高 `86%`、表单近全屏配取消/标题/确认顶栏）。确认框（`ConfirmPanel.svelte`）打开默认聚焦“取消”（导出确认默认聚焦“选择文件夹”）；忙态（如创建/加入/上传中）禁止关闭；关闭后待下层解除 `inert` 再归还焦点。
- **专用弹窗规则**：
  - **退出确认**（440px）：标题“退出登录？”，正文“清除本机曲库副本和播放队列，保留已下载歌曲”，确认键用 Primary 深薄荷“退出登录”；确认后先收起再替换历史回首页并退出。
  - **简介阅读层**（680px / 手机最高 86%）：只保留换行展示 `ui/LongText`，不猜测解析小标题或列表；焦点关闭回预览。
  - **加入歌单**：从更多菜单原地转交，顶置“新建歌单”，下接“我喜欢的音乐”（封面角标珊瑚心）与自建歌单（不含收藏歌单），不可选项写明原因。
  - **导出**（440px）：步骤切换——确认（“导出 N 首”+ 大小 + “选择文件夹”）→ 写入进度（第 N/M 首 + 进度线 + “取消”，丢弃当前首保留已完成）→ 结果（含失败明细、“删除 Campanula 内的下载”即时删不再确认、“完成”）。
  - **删除下载 / 按歌单删除 / 清空下载确认**：多选删除“删除 N 首下载？”+ 出错红“删除”（无多余说明）；单首删除不确认；按歌单删除列表仅列歌单与关联数，确认正文交代“仅删除此歌单独有的下载，其他来源的下载保留”；清空下载交代数量/大小及“同时取消 N 首下载”。

## 提示条与断网横幅

- **断网横幅**：常驻顶栏下（手机连标签吸顶），高 36px，蜜桃浅底蜜桃木字“网络已断开，只能播放已下载的歌”，内容区与侧栏让出高度，联网自动消失。
- **操作提示条（`NoticeStack`）**：应用层输出（`AppState.notices` 为唯一业务源，纯 UI 事件用 `useToast()`）。白底纸片 16px 圆角浮起阴影，最小 44px 高，仅凭 16px 前置图标区分成功/出错，操作为无底文字按钮。最多叠 3 条操作提示（播放提示另计排最底），2 秒内同动作合并计数；成功 4 秒自动消失，失败常驻至关闭，批量移除“撤销”留 5 秒并在提交时收起。
- **提示条位置**：桌面始终窗口底部正中（不因下载面板让位，层级在面板之上）；手机在迷你播放条上方（收起下载条时让开 48px，播放页或展开下载面板时挪至顶上）。登录前后双外壳均显示。
- **同步提示**：同步细条仅用于首次同步完成前；之后后台同步静默运行，仅在同步中断时发可重试的出错提示条。

## 下载面板（`DownloadPanel`）

- **出现与位置**：无任务变有任务时显示（用户手动收起后不强行展开），任务清空收起，在 `/downloads` 隐藏。桌面固定右侧（宽 360px，顶栏+断网条下 16px，底让开播放条），收起为 44px 竖条；手机底部卡片（最高 42dvh），收起为 48px 横条。属内容浮动件不进浮层栈（z-index 30）。
- **内容与退场**：标题显示状态/首数/速率，空间不足/离线/未登录原因仅在顶部说一次；行按 下载中 > 失败 > 排队 排序，上限 50 行，其余写“还有 N 首”；底部“全部取消”（原位确认）与“查看已下载”。单首下完切换 `Check` 后淡出并 200ms 收高补位，末行退完显“已下载 N 首”3 秒后收起（焦点在内最多等 8 秒）。
- **a11y**：`region` + `aria-label="下载"`，进度条 `role="progressbar"`，`aria-live="polite"` 仅在开始/完成/失败播报；打开不抢焦点，Esc 仅在焦点处于面板内时收起。

## 加载更多与局部内容切换

- **`ui/ShowMore`**：全站统一置于白色面板/网格外下方 20px 居中；加载完按钮淡出，焦点落至新追加的第一项。
- **局部内容替换**：歌单内搜索的起止/空态、登录方式、二维码步骤、歌词加载态、手机歌单网格↔排序列表，均将新旧内容叠在同一 CSS Grid 单格内交叉淡化；连续打字筛选时结果原地更新不闪烁。
