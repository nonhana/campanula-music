# 视觉基础

**北极星：「清晨的风铃草」**

整页铺一层带薄荷味的晨光底，白色面板像轻轻浮在上面的纸，薄荷绿只出现在“选中”“进度”“正在播放”“焦点”上。画面里最饱和的色彩属于歌曲封面（大量色彩饱满的动漫插画），界面主动退在封面之后。

手机与桌面共用同一套设计系统，差异只在布局与输入方式。具体色值、字号阶梯和阴影令牌以 `uno.palette.mts`、`uno.config.mts` 为唯一源头，本文件规定语义分工与约束。

## 色彩语义

高明度薄荷做底与标记，冷灰承担文字层级，蜜桃与珊瑚各司一职；粉彩色只当浅底或标记，上面一律放深色字。仅浅色主题，不做深色模式也不为其预留变量（[ADR-0008](../adr/0008-light-theme-only.md)）。

### Primary（薄荷系）

| 语义角色 | 令牌          | 用途与边界                                                                        |
| -------- | ------------- | --------------------------------------------------------------------------------- |
| 晨光底   | `primary-50`  | 全站页面底色（手机与桌面统一），非灰色                                            |
| 薄荷雾   | `primary-100` | 白色面板上的“正在播放”晨光、悬停底、歌单标签 chip 底                              |
| 薄荷玻璃 | `primary-200` | 侧栏/目录当前项底、晨光底上的“正在播放”行底、选中文字背景                         |
| 薄荷线   | `primary-300` | 输入框、描边按钮悬停边框，以及封面染底上队列当前行的晨光                          |
| 薄荷     | `primary-400` | 品牌原色默认档，界面上极少直接大面积铺底                                          |
| 新芽绿   | `primary-500` | 仅作轻装饰（如小圆点）；白底对比度仅 1.9:1，禁止用于焦点环或边框                  |
| 叶绿     | `primary-600` | Logo（Lucide `Flower`）描边，不更改形状与颜色                                     |
| 茎绿     | `primary-700` | 焦点环、输入框聚焦边框（白底 3.6:1）、波浪进度条已播段、光标与原生 `accent-color` |
| 深薄荷   | `primary-800` | 主操作按钮底（播放全部、登录、重试）、白底薄荷文字（链接、查看全部、已收藏）      |
| 森林墨   | `primary-900` | 最大播放键、薄荷浅底上的文字与图标、主操作按钮悬停态                              |

### Secondary / Tertiary / Neutral / Status

- **蜜桃系（`secondary-*`）**：专管“属于这台设备”的事——下载按钮底/悬停（浅蜜桃）、断网提示条、下载进度底；蜜桃枝为“已下载”图标，蜜桃木为下载与离线文字。
- **珊瑚心（`accent` / `#FF3040`）**：仅用于实心红心图标及“我喜欢的音乐”心形标记，不作底色。
- **中性灰（`neutral-*`）**：墨（主文字）、石墨深/石墨重（描边按钮字与图标按钮）、石墨（歌手/首数/说明）、石墨淡（时长/序号/提示，只放白底或晨光底）、发丝线（1px 边框、未播进度线）、淡发丝（无版权徽标底、面板分隔线）、纸白（面板/播放条/弹层/菜单）。
- **状态色**：试听用琥珀底配琥珀字；出错用浅红底配出错红字（下载失败、删除确认键、出错状态圆）。

### 色彩规则

- **The Morning Light Rule**：晨光底是背景，纸白是面板，薄荷绿只用于选中、进度、正在播放与焦点；画面最饱和的颜色留给封面。
- **The Dark Ink on Pastel Rule**：粉彩浅底上只放深色字（薄荷浅底配森林墨 ≥ 6.6:1，蜜桃浅底配蜜桃木 ≥ 4.8:1）；白字只放在深薄荷、森林墨、出错红等深色实心底上（≥ 6:1）。
- **The One Job per Color Rule**：每种强调色只管一件事——珊瑚管红心，蜜桃管本机与下载，琥珀管试听；禁止装饰性滥用。

## 排版

- **字体族**：自托管可变字体，回退顺序为 `Noto Sans Variable → Noto Sans SC Variable → Noto Sans JP Variable → Noto Sans TC Variable → system-ui`，不从外网加载。
- **八档字号阶梯**（UnoCSS 写法 `text-<档名>`，实例与官网共用）：
  - `headline`（600，28/36px，字距 -0.01em）：桌面页面标题；官网首页品牌名（500，森林墨）
  - `headline-sm`（600，24/32px，字距 -0.01em）：手机页面标题、桌面播放页歌名
  - `title`（600，20/28px）：首页区块标题、手机播放页歌名
  - `title-sm`（600/500，17/24px）：弹窗标题、手机区块标题、播放队列标题、空/错态标题、顶栏 `Campanula` 字样（500）
  - `body`（400/500，15/22px）：手机歌名、正文、说明、输入框文字
  - `label`（500/400，14/20px）：桌面歌名、按钮文字、导航文字、chip
  - `caption`（400/500，13/20px）：歌手、首数、时长、元信息、表头、提示、歌单标签
  - `micro`（500，11/18px）：试听、无版权、未下载徽标、手机日历按钮日期（600）
- **图形数字与等宽数字**：每日推荐日期大数字（桌面方块 56px、每日推荐页 88px、手机 72px，600）属图形元素，不计入字号阶梯；全站数字统一 `tabular-nums`。
- **The Three Real Weights Rule**：只用 400 / 500 / 600 三个真实字重，开启 `font-synthesis: none`，禁止浏览器伪粗体。
- **The Mixed Script Rule**：展示歌名、歌手、专辑、歌单名的元素必须带 `lang`：含假名标 `ja`，繁体标 `zh-TW`，其余随页面 `zh-CN`，保证假名与中英字宽整齐。

## 纵深、圆角与间距

- **间距节奏**：4px 基数，常用 8 / 12 / 16 / 20 / 24 / 32 / 40px。
- **圆角**：按钮、搜索框、标签、徽标外轮廓为胶囊（`rounded-full`）；白色面板 `16px`，网格封面与歌曲行 `12px`，行内小封面 `8px`，底部弹层顶边 `24px`，徽标 `6px`；歌手头像、播放键、封面角小圆片为正圆。无直角封面与粗描边。
- **阴影三档**：
  - **环境光**：静止白色面板、网格封面、搜索框。
  - **浮起**：菜单、底部弹层、弹窗、播放条、迷你条、搜索下拉、播放页大封面、触屏滚动条气泡。
  - **小圆片（`shadow-chip`）**：压在封面上的白色标记圆片（正在播放竖条圆片、我喜欢的音乐角标心形、搜索网格收藏角标），确保在任何色相封面上可辨认。
- **The Ambient Light Rule**：静止面板只用环境光；浮起阴影只给浮在内容上、可关闭或松手即散的层。
- **The Light-Only Fog Rule**：播放页封面染底将封面放大重度模糊（64px，饱和度 1.15）后叠 ≥ 80% 白纱，始终保持浅色、深色封面上次要文字对比度 ≥ 4.5:1。
- **对比度与焦点环**：
  - 播放队列全部可见文字（含滚动边缘）与歌词主体阅读区文字保持 ≥ 4.5:1；歌词上下滚动边缘作为特例使用柔和渐隐遮罩（强制颜色模式下关闭），播放队列不加正文渐隐；纸白队列当前行时长用石墨色。
  - 全局焦点环为 2px 茎绿、外偏 2px；歌曲行与播放页歌词区焦点环画在内侧 2px（歌词区外侧用深薄荷），防止被裁切或压住相邻行。

## 无障碍、大字号与强制颜色

- **大字号自适应**：歌曲行保持默认高度，但在文字放大或增大字距时允许行高随文字块自然增长，虚拟列表、定位与排序共用该实际高度，防止重叠。
- **强制颜色模式（`forced-colors: active`）**：选中态用系统色轮廓标出，保留焦点外圈，进度与音量轨道/滑块使用系统色；不改变普通浅色主题的颜色与尺寸。

## 禁止清单（Don't）

- 禁止在薄荷、蜜桃、珊瑚粉彩浅底上放白字；禁止用近黑（`#111827`）作实心按钮底色。
- 禁止用 emoji 或 Unicode 字符（`•••`、`▶`、`♥`）冒充图标；全站统一用 Lucide 图标。
- 禁止悬停专属操作；禁止要求双击才播放。
- 禁止在手机上把次级操作做成与主操作同体量的描边胶囊。
- 禁止在底部播放条塞入音质、歌词开关等次级控件（放进播放页）。
- 禁止对非打断型任务开居中弹窗（搜索结果是内容区整页，非居中弹窗）。
- 禁止首屏弹出无关提示或浮动按钮压住列表（唯一例外：“定位到正在播放”，仅在当前行不在视口内时浮出）。
- 禁止让 Logo 常驻旋转、修改其形状/颜色，或预留深色模式。
- 禁止在虚拟列表滚动挂入的新行上播放入场动画。
