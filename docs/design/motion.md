# 动效、手势与自绘滚动条

## 动效哲学与核心规则

动效只回答三件事：操作是否生效、元素从哪来到哪去、当前处于什么状态。风格轻缓无回弹，封面是画面主角，动效围绕封面展开。

- **The Float Rule**：来有来处、去有去向；每个飘入从来源方向滑入并停稳，飘出向去向散开；不弹、不晃、不为装饰旋转。
- **The Cover Leads Rule**：同一时刻只允许一张封面飞行；飞行必须落在已加载好的图片上，终点不可见或图片未到则退回普通飘入。

## 时长、曲线与通用规则

- **曲线**：飘入与位移用 `ease-out-soft`（`cubic-bezier(0.16, 1, 0.3, 1)`），飘出用 `ease-in-soft`（`cubic-bezier(0.4, 0, 1, 1)`）；禁止回弹弹簧（仅歌曲格吸附使用过阻尼无回弹弹簧）。
- **飘入 / 飘出距离**：常规元素飘入 12px、飘出 6px；整页飘入 16px、飘出 8px。新内容不等旧内容退完，飘出开始 60ms 后即可飘入。
- **四档时长**：
  - 反馈：120ms（按下、图标切换、细线加粗）
  - 状态：进 200ms / 出 120ms（行状态、浮动菜单、提示条、按钮显现）
  - 面板与页面：进 360ms / 出 200ms（换页、歌词/队列切换、弹窗；抽屉 380ms）
  - 主角：600ms（播放页换碟、开场 Logo 飞入）；播放条小转盘与封面飞行 480ms。整段换页 ≤ 500ms。
- **方向约定**：进下一层由下浮上，返回由上沉下；同层切换（手机曲库标签、歌词/队列、登录方式）横向移动；下一首向左转、上一首向右转。
- **依次飘入**：仅在一组内容从骨架首次显现时生效（骨架 120ms 淡出，前 6 项每项错开 30ms 浮入 240ms，其余随第 6 项）；已有缓存直接打开、换页整体过渡、虚拟列表滚入行不逐行飘入。
- **随时可打断与后台静止**：所有动画可半途转向新终点；页面在后台（`document.hidden`）时 `motion.ts` 时长归 0、图片加载完直接显示，回前台不补放；返回恢复筛选/滚动位置通过 `atOnce()` 直达。
- **只动合成属性**：仅对 `transform`、`opacity`、`filter`、`clip-path` 做动画。唯一允许的布局高度动画为一次性结构变化（`unfold` / `animateHeight`）：侧栏展开 200ms、单条提示展开收起 200ms、登录卡片切换高度 360ms、手机歌单排序切态 360ms、下载面板完成行收高 200ms、以及不推开布局的悬浮细线加粗 120ms（底栏进度线、滚动条）。
- **图片加载**：未缓存的封面/头像加载完成后 240ms 淡入；本次会话已缓存的直接显示。
- **减少动态效果（`prefers-reduced-motion: reduce`）**：去掉所有位移、旋转、缩放、飞行与循环动画（波浪流动、竖条、骨架扫光、转圈），仅保留 ≤ 150ms 淡入淡出和颜色变化；手势拖动仍跟手，松手直接到位。令牌层自动降级，组件内不手写媒体查询。

## 页面过渡、封面飞行与开场

### 页面切换（[ADR-0011](../adr/0011-page-transitions-use-view-transitions.md)）

- 通过 SvelteKit `onNavigate` 调用原生 `document.startViewTransition`，仅内容区过渡，顶栏/侧栏/播放条（`view-transition-class: still`）原地不动。
- 桌面歌单页左栏切换歌单时，左栏标记 `still` 不动，右栏仅 200ms 交叉淡化，被点行封面不飞；其余从网格进入歌单/专辑/歌手页时封面飞向页头（480ms），返回时飞回原格（原格不在视口或非格子进入则不飞；两端共用 `FLIGHT_COVER_SIZE` 200px 缩略图，终点图最多等 100ms）。
- 返回页面在拍新帧前恢复滚动位置；过渡期间的点击直接结束过渡并生效；系统手势已有预览时不叠画。

### App 开场与整屏换屏

- **打开中 → 首屏**：首帧（`src/app.html`）在晨光底正中静止显示 40px 四瓣花；校验账号完成后新屏 360ms 淡入，花沿浅弧线飞至左上角 Logo 处缩成 28px（600ms），落定前“Campanula”字样右飘 12px 显现（200ms）；内容区拆块按距落点远近依次飘入（160ms 起、最远晚 320ms、从 6px 模糊清澈至清晰，视口外不动）。无左上角 Logo（手机直达二级页）时花原地淡出上飘 6px、内容由中央漾开。
- **整屏换屏**（登录、退出、失效、出错重试）：新屏淡入 360ms，旧屏 `out:fadeAway` 原地 200ms 淡出且不占高。
- **官网首页**：直接打开或刷新时中央小花旋转约 750ms 后飞向字标左侧，正文与链接按距落点依次展开（共用 `opening-dom.ts`）；键盘或切后台立即结束开场；进/退指南页时花标、字标与 GitHub 图标通过跨文档 View Transitions 往返。

## 手势、拖动与自绘滚动条

### 通用拖动终止协议（`shared/press.ts`）

抽屉、封面转盘、进度条/滚动条滑块、拖动排序、鼠标拖着滚、封面取景框共用同一套指针生命周期：

- 仅真实松开（或 Chromium 键已松开时主动收回指针捕获）提交结果；拖动中右键、切窗、页面隐藏、`pointercancel` 一律作废并复原。
- 拖过之后的紧邻 `click` 拦截不触发点按；拦截浏览器原生拖拽链接/图片。
- 起拖阈值按控件定：多数按下即接手，鼠标拖着滚 5px，滚动条触屏快速定位纵向 6px。
- **壳层触控与轻震（`shared/haptic.ts`）**：按钮、标签与顶栏/导航链接禁选字与长按菜单并设 `touch-action: manipulation`，图片禁长按呼出浏览器菜单（歌词、简介与输入框保持可选中）。仅在触屏主指针且未开启减少动态效果时，于滚动条快定位接手、手机长按歌曲行进多选、横划封面提交切歌与点亮红心时触发 10ms 轻震。

### 鼠标拖着滚（`shared/drag-scroll.ts`）

适用于横向架子与首页歌曲格，仅响应鼠标（触屏与触控板交由浏览器原生处理）：

- 拖过 5px 起拖，光标呈抓手、禁止选字。
- 松手惯性参照 Flutter macOS 滚动逐帧计算（[ADR-0012](../adr/0012-native-scroll-custom-scrollbar.md)）：近三段速度加权 `0.15 / 0.65 / 0.2`，末移超 40ms 或速度 ≤ 100px/s 不滑；架子按摩擦减速（每秒留 0.135 且减 1400px/s），歌曲格用过阻尼弹簧（质量 0.3、劲度 75、阻尼比 1.3）无回弹停在目标列。任意按下/滚轮/键盘操作立即中止惯性；按停不触发点击。减少动态效果时松手即停。

### 抽屉跟手

播放页、手机播放队列、底部菜单与手机弹窗共用（`drawer-core.ts`）：起拖记录尺寸与位移，移动直接写像素位移不重复测量布局，面板挂载期间保留 `transform` / `will-change`；手机播放队列挂于播放页内独立 `100dvh` 定位容器。超拉带对数阻尼 `8·(ln(v+1)−2)`（上限 48px，底部多垫 48px 底色）。

### 自绘滚动条（`ui/Scrollbar.svelte`）

- 页面、播放队列、歌单左栏、横向架子、弹层共用；歌词与首页横向歌曲格不显示。
- 平时宽 4px、全圆角、石墨淡 45%，滚动时 120ms 淡入、停滚 1 秒后 200ms 淡出；鼠标悬停贴边 16px 热区或拖动时加粗至 8px 并变茎绿，点击轨道空白处平滑翻一屏，不进 Tab 顺序，除听众交互外绝不主动改写滚动位置。
- **触屏快速定位**：列表超 4 屏且细条亮着时，滑块周围 44px 宽（上下各延 12px）隐形热区不拦截点按/长按，仅纵向滑过 6px 接手（横向交还浏览器）；接手变 8px 茎绿并轻震，歌曲列表左侧浮现白底 `shadow-float` 气泡显示顶行序号与歌名。
- **拖歌排序让位规则**：在手机多选拖排中，歌曲把手落在右侧快速定位窄条内时，必须先向左离开窄条，之后再拖回窄条才会激活快速定位，防止微调几行时误跳几千首。

## 写在哪（实现映射与 Lint 门禁）

- **唯一数值源**：`src/lib/components/shared/motion-tokens.ts`（含时长、曲线、`WHEEL`、`FLIGHT_ARC`）。禁止在代码与样式中硬编码 `duration-150`、`ease-out`、`motion-reduce:`、`150ms`、`cubic-bezier(...)` 或阶梯外 arbitrary class（`tests/tools/check-design-tokens.mts` 在 `pnpm lint` 时强制拦截）。
- **CSS / UnoCSS**：透明度与颜色用 `duration-<档名>`，位移/缩放/字号用 `duration-move-<档名>`，曲线用 `ease-out-soft` / `ease-in-soft`，按钮按下用 `press`，组件 `<style>` 用 `var(--duration-*)` / `var(--move-*)` / `var(--ease-*)` / `var(--loop-state)`。
- **Svelte 过渡**：统一用 `src/lib/components/shared/motion.ts` 的 `float`、`fade`、`fadeAway`、`reveal`（组标 `data-reveal-group`）、`iconSwap`、`pop`、`toast`、`unfold`、`animateHeight`、`fadeThrough`、`stagger`、`dock`、`recede`。会被连按打断的过渡必须写单个 `transition:` 而非拆成 `in:` / `out:`；原地替换内容叠在同一 CSS Grid 单格内交叉淡化；仅在外层 `{#if}` 条件出现且非页面内容时按需加 `|global`。
- **专用模块**：换页方向在 `shell/page-transition.ts`；封面飞行尺寸在 `library/flight.ts`；点歌飞入播放条在 `player/cover-flight.svelte.ts`；换碟与左右滑在 `player/CoverWheel.svelte`、`player/wheel-core.ts`、`player/cover-swipe.svelte.ts`（帧内禁止读 DOM 样式/布局，宽度由 `ResizeObserver` 缓存）；开场动画在 `boot/opening.ts` 与 `boot/opening-dom.ts`。
