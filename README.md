<h3 align="center">Campanula Music</h3>

<p align="center">
  开源的第三方网易云音乐播放器，基于 Svelte 5 + SvelteKit + UnoCSS 与
  <a href="https://github.com/nonhana/hana-music-api"><code>hana-music-api</code></a>
  <br />
  登录自己的网易云账号直达曲库，支持在线播放、歌单整理与离线下载。
</p>
